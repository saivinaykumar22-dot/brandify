BRANDIFY HOW IT WORKS — STEP 01
===================================

Files:
- how-it-works-step1.html
- how-it-works-step1.css
- how-it-works-step1.js
- assets/daily-wellness-capsules.jpg
- assets/plant-protein-blend.jpg
- assets/hydrating-face-cream.jpg

INSTALLATION:
1. Add the HTML block from how-it-works-step1.html inside your existing
   How It Works section at the Step 01 content location.
2. Add all CSS from how-it-works-step1.css at the bottom of your existing
   main stylesheet.
3. Add all JavaScript from how-it-works-step1.js at the bottom of your
   existing main script, or load it after the HTML.
4. Keep the assets folder beside the HTML file that contains the section.
   The HTML uses:
       assets/daily-wellness-capsules.jpg
       assets/plant-protein-blend.jpg
       assets/hydrating-face-cream.jpg

FUNCTIONALITY:
- Category tab filtering
- Search filtering
- Filter toggle
- Favorite button state
- Select Product state
- Clear selected product
- Make It Yours button attempts to move to Step 02
- A custom "hiw:next-step" event is emitted if Step 02 is not found

IMPORTANT:
The product image assets are cropped from the supplied reference image.
They are image files, not CSS/SVG recreations.
